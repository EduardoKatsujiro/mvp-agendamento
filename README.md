# 📅 Sistema de Agendamento Comunitário (MVP)

Projeto de Extensão Universitária desenvolvido para a UNIVALI.
Este é um Produto Mínimo Viável (MVP) focado em resolver a desorganização de agendamentos para profissionais autônomos locais, através de uma interface web simplificada e integração direta com o WhatsApp, sem necessidade de login.

## 🚀 Tecnologias Utilizadas
* **Linguagem:** Python 3.12+
* **Framework Web:** Streamlit
* **Integração:** API de redirecionamento do WhatsApp

## 📂 Estrutura de Arquivos
* `streamlit_app.py`: Código-fonte principal da aplicação e interface gráfica.
* `requirements.txt`: Lista de dependências (bibliotecas) necessárias.
* `iniciar_sistema.bat`: Arquivo executável para rodar o sistema localmente no Windows.
* `README.md`: Documentação do projeto.

## ⚙️ Como executar o projeto localmente
1. Certifique-se de ter o Python instalado no seu computador.
2. Clone este repositório.
3. Instale as dependências executando no terminal: `pip install -r requirements.txt`
4. Execute o sistema com o comando: `streamlit run streamlit_app.py`
5. (Apenas Windows) Você também pode dar um duplo clique no arquivo `iniciar_sistema.bat`.

## 🌐 Acesso ao Sistema em Nuvem
O sistema está hospedado e pode ser acessado diretamente pelo navegador através do link oficial fornecido no relatório.
